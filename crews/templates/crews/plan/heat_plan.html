{% translate "Water, rest and shade" %}

  • {% translate "Cool drinking water close to the work, enough for 1 quart per worker per hour. Drink 1 cup every 15–20 minutes, even when not thirsty." %}
  • {% translate "Shade big enough for everyone on break to sit at the same time, as close to the work as possible." %}
  • {% translate "Anyone may take a rest in shade at any time to prevent overheating. Rest at least 5 minutes and until they feel better." %}
  • {% translate "Buddies check on each other at the times above. Reply to Shadebreak texts: 1 = OK, 2 = needs help." %}

{% translate "Warning signs and first aid" %}

{% translate "Heat exhaustion" %}

{% translate "Heavy sweating, cool pale clammy skin, fast weak pulse, nausea or vomiting, muscle cramps, tiredness or weakness, dizziness, headache, fainting." %}

  • {% translate "Stop work. Move to shade or a cool place." %}
  • {% translate "Loosen clothing. Cool with wet cloths and fanning." %}
  • {% translate "Sip cool water." %}
  • {% translate "Get medical help if they vomit, get worse, or are not better within an hour. Do not leave them alone." %}

{% translate "Heat stroke: a medical emergency" %}

{% translate "Confusion, slurred speech, acting strange, fainting or seizures, very high body temperature, hot red skin that may be dry or damp." %}

  • {% blocktranslate with number=crew.emergency_number %}Call {{ number }} now.{% endblocktranslate %}
  • {% translate "Cool them right away: cold water or ice on the body, ice-water immersion if available, wet towels and fanning." %}
  • {% translate "Stay with them. Do not give drinks if they are confused or not fully awake." %}
  • {% translate "Send someone to meet the ambulance and guide it in." %}

{% translate "In an emergency" %}

  1. {% blocktranslate with number=crew.emergency_number %}Call {{ number }}. Say: "Heat emergency," the site address and the closest cross street.{% endblocktranslate %}
  2. {% translate "Start cooling the worker while you wait. Keep cooling until help arrives." %}
  3. {% blocktranslate with name=crew.lead_name|default:_("the crew lead") %}Tell {{ name }} right away.{% endblocktranslate %}
